## TASK 3 — ADD THROTTLING TO SCROLL ANIMATION LISTENER

**File:** script.js
**Problem:** `animateOnScroll()` is called on every `scroll` event with no throttling. It calls `getBoundingClientRect()` on every element on every scroll tick, which is expensive.
**Fix:**
- Wrap the scroll listener with a throttle using `requestAnimationFrame`:

```js
let scrollTicking = false;
window.addEventListener('scroll', () => {
  if (!scrollTicking) {
    requestAnimationFrame(() => {
      animateOnScroll();
      scrollTicking = false;
    });
    scrollTicking = true;
  }
});
```
- Replace the existing bare `window.addEventListener('scroll', animateOnScroll)` call with this throttled version.
- Also apply the same pattern to the existing `window.addEventListener('scroll', ...)` that handles the navbar style and scroll-to-top button visibility. All three scroll handlers (navbar, scroll-top button, animateOnScroll) should be merged into one rAF-throttled listener.

## TASK 6 — FIX MOBILE MENU: CLOSE ON OUTSIDE CLICK

**File:** script.js
**Problem:** Mobile navigation menu can only be closed by clicking the hamburger toggle. Clicking outside the menu does nothing.
**Fix:** Add a document-level click listener that closes the menu when a click lands outside both the nav element and the toggle button:

```js
document.addEventListener('click', (e) => {
  const navMenu = document.getElementById('nav-menu');
  const navToggle = document.querySelector('.nav-toggle');
  if (navMenu && navToggle && navMenu.classList.contains('active')) {
    if (!navMenu.contains(e.target) && !navToggle.contains(e.target)) {
      navMenu.classList.remove('active');
      navToggle.classList.remove('active');
    }
  }
});
```

## TASK 11 — REPLACE SCROLL ANIMATION QUERIES WITH IntersectionObserver

**File:** script.js
**Problem:** The `animateOnScroll` function loops over all `.animate-on-scroll` elements and calls `getBoundingClientRect()` on each one every scroll tick. This is a known performance antipattern (forced layout/reflow).
**Fix:** Replace the entire `animateOnScroll` function and its scroll listener with an `IntersectionObserver`:

```js
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
      observer.unobserve(entry.target); // stop watching once visible
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.animate-on-scroll').forEach(el => observer.observe(el));
```

Remove the old `animateOnScroll()` function and its `scroll` event listener entirely.

## TASK 14 — PROVIDE IMAGE OPTIMIZATION BASH COMMANDS

**Context:** The images/ directory contains unoptimized files totalling ~41 MB. This task does not change HTML/CSS/JS — it provides the shell commands to run once in the project root to generate optimized variants.
Add these commands as comments at the bottom of nextsteps.txt (or as a separate shell script `optimize-images.sh`):

```bash
#!/usr/bin/env bash
# Requires: imagemagick (brew install imagemagick) and cwebp (brew install webp)
# Run from project root

cd images

for f in 1.jpg 2.jpg 3.jpg 4.jpg 6.png 8.jpg 9.jpg AboutUs.jpg; do
  base="${f%.*}"
  # Create medium (960w) and small (480w) variants
  convert "$f" -resize 960x -quality 80 "${base}-medium.jpg"
  convert "$f" -resize 480x -quality 75 "${base}-small.jpg"
  # Create WebP versions (optional but recommended)
  cwebp -q 80 "$f" -o "${base}.webp"
done

# Optimize banner for mobile
convert banner.jpg -resize 768x -quality 80 banner-mobile.jpg

echo "Done. Check image sizes:"
du -sh *.jpg *.png *.webp 2>/dev/null | sort -h
```
